bloom.flow
bloom.flow is an aesthetic productivity workspace designed to help you focus, organize your day, and create an environment that feels personal.

Features
Unlimited focus sessions from 15 minutes to 999 hours
Digital clock with second-by-second time
Short and long break modes
Daily focus streak tracking
Timed to-do list
Personal notes pad
Spotify, Apple Music, and ambient music options
Vibrant selectable themes
Custom background image upload
Full-screen focus mode
Floating timer window
Language selection
Responsive design for desktop and mobile
Design
bloom.flow uses an atmospheric visual style with vibrant gradients, soft glassmorphism, glowing accents, and minimal controls designed to keep attention on the current session.

Tech Stack
Next.js
React
TypeScript
Tailwind CSS
Lucide icons
Vercel deployment
Getting Started
Clone the repository, install the dependencies, and start the development server:

npm install
npm run dev
Then open http://localhost:3000 in your browser.

Project Status
bloom.flow is currently an evolving productivity workspace. The core focus timer and personalization features are available, with additional integrations and account features planned for future releases.

Roadmap
