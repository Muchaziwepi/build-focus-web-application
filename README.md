# 🌸 bloom.flow

### Find your flow. Focus on what matters.

**bloom.flow** is an aesthetic productivity workspace designed to help you focus, organize your day, and create a digital environment that feels uniquely yours.

Combining a customizable focus timer, task management, personal notes, and ambient music options, bloom.flow transforms your workspace into a calming, personalized space where productivity feels natural.

---

## ✨ Features

### ⏱️ Focus & Time Management
- Unlimited focus sessions ranging from 15 minutes to 999 hours
- Real-time digital clock with second-by-second updates
- Short and long break modes
- Daily focus streak tracking
- Full-screen focus mode
- Floating timer window

### 📝 Productivity Tools
- Timed to-do list to organize daily tasks
- Personal notes pad for capturing ideas and thoughts
- Focus tools designed to minimize distractions

### 🎨 Personalization
- Vibrant, selectable color themes
- Custom background image uploads
- Atmospheric gradients and glowing visual accents
- Soft glassmorphism for a modern, immersive interface
- Language selection

### 🎵 Music & Atmosphere
- Spotify integration options
- Apple Music integration options
- Ambient music options to create your ideal focus environment

### 📱 Responsive Experience
- Responsive layouts for desktop and mobile devices
- Minimal controls and an intuitive interface
- A personalized workspace designed around your preferences

## 🚀 Getting Started

Follow these steps to run bloom.flow locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (compatible with your project's Next.js version)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/bloom.flow.git
```

**2. Navigate to the project directory**

```bash
cd bloom.flow
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
